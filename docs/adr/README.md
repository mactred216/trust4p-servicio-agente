# Registro de decisiones de arquitectura (ADR)

Formato: [Michael Nygard](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions) (Contexto / Decisión / Consecuencias). Un ADR se escribe cuando la decisión ya está tomada e implementada, no antes.

Este servicio numera sus propios ADR de forma independiente a `trust4p-api-negocio` — son dos repos, dos historiales de decisiones. Las decisiones que afectan a ambos servicios (p. ej. ADR-005, la separación entre el motor de cálculo y la generación asistida) se documentan en `trust4p-api-negocio` por ser donde vive el componente que la origina, y se referencian desde aquí cuando aplique.
